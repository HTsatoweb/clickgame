Infinity Matrix Omega - Complete ModAPI Technical Reference

プロフェッショナルMOD開発者のための全エンドポイント、限界値・計算精度制御システム、およびイベントフック完全拡張リファレンス

アーキテクチャ概要: window.ModAPI はゲームのメインスレッドおよびグローバルスコープ（gameオブジェクト、各種計算関数、Decimalコンテキスト）と完全に同期しています。新規追加された限界値（Threshold）および精度管理（Decimal Config）APIにより、極限の数値シミュレーションやエンドレスモード拡張が完全にサポートされます。

1. 内部データ構造・型安全性と新規拡張モジュール

本システムでは、肥大化する数値を扱うために decimal.js（ラップ関数 D()）を採用し、状態変化のたびに自動的に refreshUI() がコールされます。

  • エネルギー・限界値管理 (currentEnergyThreshold / infinityDecimal): ゲームの勝利条件やオーバーフロー上限を動的に変更するためのステートが拡張されました。文字列・数値・Decimalオブジェクトのいずれも安全にバリデーションされます。
  • 計算精度制御 (Decimal.set() ラッパー): precision, rounding, toExpNeg, toExpPos などの小数・指数演算パラメータを外部から動的にチューニング可能です。

3. イベントフックシステム (Hooks) の拡張と詳細

window.ModAPI.registerHook(hookName, callback) を使用することで、コアロジックを改変せずに独自のリスナーを安全に登録できます。

サポートされているフック一覧

  • onTick: メインゲームループの1フレームごとに発火。
  • onCoreClick: プレイヤーが中央コアをクリックした瞬間に発火。
  • onPrestigeAm / onPrestigeTl / onPrestigeGx: 各種プレステージ実行時に発火。
  • onBuyFactory / onBuyUpgrade: 施設やアップグレード購入時に発火。
  • onSave: セーブシリアライズ実行時に発火。
  • onAchievement (New): 実績達成時やアチーブメント解除トリガー時に発火。

4. 拡張APIを活用したプロフェッショナルMODの実装例

応用例: 精度チューニング & 無限エンドレス化オーバーライドMOD

// 1. 計算精度の動的向上とInfinity上限の引き上げ window.ModAPI.setDecimalConfig({ precision: 50, // 精度を50桁に拡張 rounding: 4 // HALF_UP 丸めモード }); window.ModAPI.setInfinityDecimalLimit("1e1000000"); // 上限を1e1,000,000に拡張 window.ModAPI.setEndingEnergyThreshold("1e5000"); // クリア条件を先送り // 2. 新規追加された onAchievement フックの利用例 window.ModAPI.registerHook('onAchievement', (achievementId) => { console.log("[ProMod] Achievement unlocked! ID:", achievementId); // 達成ボーナスとしてタイムシャードを自動付与 window.ModAPI.addTimeShards(100); }); // 3. onTick によるカスタムCPSモニタリング window.ModAPI.registerHook('onTick', () => { const cps = window.ModAPI.getCalculatedCps(); if (cps.gte("1e100")) { // 爆発的生産フェーズに入った場合の自動最適化 window.ModAPI.setAutomationFactoryState(true); } }); console.log("[ProMod] Precision and Limit override mod successfully loaded.");
