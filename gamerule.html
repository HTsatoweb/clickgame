拡張版 ModAPI 完全リファレンス & 実装ガイド

放置ゲームの限界値・計算精度制御および全エンドポイントの具体的な使用例集

このドキュメントについて: 本ガイドでは、追加された新機能（エネルギー閾値やDecimal精度変更）を含むすべての window.ModAPI の仕様、分類ごとの操作方法、および実践的なMODコードの書き方を網羅しています。

1. 今回追加された新機能（限界値・計算精度の動的制御）

ゲームの天井であるエネルギー限界値や、巨大数計算を支える decimal.js の内部パラメータを外側から安全に書き換え・取得できるようになりました。

  • エネルギー終了閾値 (Ending Energy Threshold): ゲームクリアや特殊演出のトリガーとなる目標エネルギー値の変更・取得。
  • 無限大判定の限界値 (Infinity Decimal Limit): どこまでを有限の数値として扱い、どこからを無限とみなすかの上限値。
  • Decimal計算精度の動的変更 (Decimal Config): 演算精度（precision）や丸めモード、指数表現の閾値を変更し、重い処理の軽量化や高精度化を動的に行えます。
// --- 新機能の操作例 --- // 1. 計算精度を軽くするために 16 に下げる window.ModAPI.setDecimalConfig({ precision: 16 }); // 2. 現在のDecimal設定を確認する console.log(window.ModAPI.getDecimalConfig()); // 3. クリア条件・終了エネルギーの閾値を大幅に引き上げる window.ModAPI.setEndingEnergyThreshold("1e5000"); // 4. 無限大のしきい値を変更する window.ModAPI.setInfinityDecimalLimit("1e4000");

2. ModAPI 全エンドポイント一覧と使い方

カテゴリ 主要関数名 引数 / 戻り値 説明・動作
エネルギー管理
(1-5)		 getEnergy() 引数なし / 戻り値: Decimal 現在のエネルギー量を Decimal 型で取得します。
setEnergy(v) 引数: v (数値/文字列/Decimal) エネルギーを指定した値に直接書き換えます（負数は0に補正）。
addEnergy(v) 引数: v 現在のエネルギーに指定した値eyを加算します。
subEnergy(v) 引数: v 現在のエネルギーから指定した値を減算します（0未満にはなりません）。
clearEnergy() 引数なし エネルギーを 0 にリセットします。
反物質 (Antimatter)
(6-10)		 getAntimatter() 引数なし / 戻り値: 数値/Decimal 現在の反物質の量を取得します。
setAntimatter(v) 引数: v (数値) 反物質の量を直接設定します。
addAntimatter(v) / subAntimatter(v) 引数: v (数値) 反物質を加算・減算します。
clearAntimatter() 引数なし 反物質を 0 にリセットします。
タイムシャード (Time Shards)
(11-15)		 getTimeShards() 引数なし タイムシャードの現在値を取得します。
setTimeShards(v) / addTimeShards(v) / subTimeShards(v) 引数: v タイムシャードの値を設定・加算・減算します。
clearTimeShards() 引数なし タイムシャードを 0 にリセットします。
銀河ノード (Galaxy Nodes)
(16-20)		 getGalaxyNodes() 引数なし 銀河ノードの現在値を取得します。
setGalaxyNodes(v) / addGalaxyNodes(v) / subGalaxyNodes(v) 引数: v 銀河ノードの値を設定・加算・減算します。
clearGalaxyNodes() 引数なし 銀河ノードを 0 にリセットします。
ファクトリー・アップグレード
(21-34)		 getFactoryCount(id) / setFactoryCount(id, v) / addFactoryCount(id, v) 引数: id (数値), v (数値) インダストリアルファクトリーの保有数操作を行います。
getUpgradeLevel(id) / setUpgradeLevel(id, v) 引数: id, v 通常アップグレードのレベル操作を行います。
setAllUpgradesToMax()
setAllAmUpgradesToMax()
setAllTlUpgradesToMax()		 引数なし 対応するすべてのアップグレードを一括で最大レベルにします。
高度な計算・予測
(36-46)		 getCalculatedCps() 引数なし 現在の1秒あたりの総生産量 (CPS) を取得します。
getCalculatedGameSpeed() / getCalculatedProductionMultiplier() 引数なし ゲームの速度倍率や全体生産倍率を取得します。
getFutureEnergyEstimate(seconds) 引数: seconds (秒数) 指定秒数経過した後のエネルギー予測値を算出します。
自動化・プリステージ・システム
(47-56)		 executePrestigeAmShift(forcedGain) 引数: forcedGain (任意) 反物質リセット（プレステージ）を実行します。
setAutomationFactoryState(bool)
setAutomationUpgradeState(bool) 등		 引数: bool (true/false) 各オートメーション機能の有効・無効を切り替えます。
executeSaveSerialization() / executeHardResetWipe() 引数なし 手動セーブの実行、またはハードリセット（全データ消去）を行います。
フック・イベント
(57-65)		 registerHook(hookName, callback) 引数: hookName (文字列), callback (関数) ゲーム内イベント（onTick, onCoreClick, onBuyFactory 等）に独自の処理を割り込みさせます。

3. 実践：MOD作成の具体例

例1: 自動チート・オートクリッカーMOD（毎秒エネルギーを自動加算 & 自動アップグレード）

// 毎秒のティックイベントにフックを登録する window.ModAPI.registerHook('onTick', () => { // 毎秒 1e10 のエネルギーを自動で追加する window.ModAPI.addEnergy("1e10"); // 資産が潤沢になったらすべてのアップグレードを自動で最大にする（お好みで） if (window.ModAPI.getEnergy().gte("1e15")) { window.ModAPI.setAllUpgradesToMax(); } }); console.log("[MyMod] Auto-Energy & Max-Upgrade Mod loaded successfully!");

例2: パフォーマンス軽量化 & 限界突破MOD（計算精度変更 ＆ 超・長期放置対応）

// 1. 計算精度を落として動作を爆速・軽量化し、巨大数対応を拡張する window.ModAPI.setDecimalConfig({ precision: 14, // 精度を少し下げて負荷を軽減 toExpNeg: -9, toExpPos: 9 }); // 2. 終了エネルギーの限界値を遥か彼方へ引き上げ、まだまだ遊べるようにする window.ModAPI.setEndingEnergyThreshold("1e10000"); window.ModAPI.setInfinityDecimalLimit("1e9000"); console.log("[PerformanceMod] Precision optimized and energy threshold extended!");

例3: クリック時ボーナス付与フックMOD

// コアクリック時に発動するフック window.ModAPI.registerHook('onCoreClick', (event) => { // クリックするたびに追加のタイムシャードをボーナス付与する window.ModAPI.addTimeShards(5); console.log("[BonusMod] Click detected! Awarded +5 Time Shards."); });
