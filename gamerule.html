Infinity Matrix Omega - Advanced ModAPI Specification

プロフェッショナルMOD開発者のための内部構造、全エンドポイント詳細、およびイベントフック応用リファレンス

アーキテクチャ概要: window.ModAPI はゲームのメインスレッドおよびグローバルスコープ（gameオブジェクト、各種計算関数）と完全に同期しています。すべての副作用を伴う操作の後は自動的に refreshUI() がコールされ、画面が即座に再描画されます。

1. 内部データ構造と安全な型ハンドリング

本ゲームでは、肥大化する数値を扱うために decimal.js（ラップ関数 D()）を採用しています。

  • エネルギー (game.energy): 内部では Decimal インスタンスとして保持されます。setEnergy 等に渡す際は数値、文字列、Decimalオブジェクトのいずれも許容されますが、内部で自動的に decMax0() を通るため負数になることはありません。
  • 反物質・タイムシャード・銀河ノード: それぞれ数値またはDecimalで管理されており、型安全なバリデーション（typeof v === 'number' && !isNaN(v)）を経由して代入されます。

2. 全エンドポイント詳細リファレンス

■ 資源管理・操作系API

メソッド名 引数 戻り値 詳細仕様・エラーハンドリング
getEnergy() なし Decimal 現在のエネルギーインスタンスを直接返します。参照渡しのため直接書き換えは厳禁です。
setEnergy(v) v (数値 / 文字列 / Decimal) なし decMax0(v) でクランプ処理後、代入と refreshUI() を実行。
addEnergy(v) / subEnergy(v) v (数値 / 文字列 / Decimal) なし Decimal演算による加減算を行います。減算時は 0 未満にならないよう自動調整されます。
getAntimatter() / setAntimatter(v) v (数値) 数値 反物質の取得およびバリデーション付き代入。NaNや非数値を完全に弾きます。

■ ファクトリー・アップグレード系API

メソッド名 引数 戻り値 詳細仕様・エラーハンドリング
getFactoryCount(id) id (整数) 数値 指定IDのファクトリー保有数を返します。存在しないIDの場合は 0 を安全に返却。
setFactoryCount(id, v) id, v (整数) なし 配列の境界値チェック（0 <= id < game.facCounts.length）を通過した場のみ代入。

getFutureEnergyEstimate(seconds) seconds (数値) Decimal 現在から指定秒数経過したときの予測エネルギー量を即時計算します（シミュレーション用）。

3. イベントフックシステム (Hooks) の徹底活用

window.ModAPI.registerHook(hookName, callback) を使用することで、ゲームのコアロジックを書き換えることなく独自のリスナーを差し込むことができます。

サポートされているフック一覧

  • onTick: メインゲームループの1フレーム（毎秒複数回、またはティック毎）ごとに発火。
  • onCoreClick: プレイヤーが中央のコアをクリックした瞬間に発火（イベント引数を取得可能）。
  • onPrestigeAm / onPrestigeTl / onPrestigeGx: 各種プレステージ（転生）実行時に発火。
  • onBuyFactory / onBuyUpgrade: 施設やアップグレード購入時に発火。
  • onSave: セーブシリアライズ実行時に発火。

4. 高度なプロフェッショナルMODの実装例

応用例: 高度な自動売買 & カスタム実績トラッカーMOD

// 1. カスタムステータスの保持用オブジェクト const CustomModState = { totalBonusEarned: 0, lastCheckedCps: 0 }; // 2. onTick フックを用いた毎秒の監視と自動最適化ロジック window.ModAPI.registerHook('onTick', () => { const currentCps = window.ModAPI.getCalculatedCps(); // 生産効率が急上昇したときにコンソールへログ出力 if (currentCps.gt(CustomModState.lastCheckedCps * 2)) { console.log("[ProMod] Production doubled! Current CPS:", currentCps.toString()); } CustomModState.lastCheckedCps = currentCps.toNumber(); }); // 3. クリック時のインターセプトとボーナス付与 window.ModAPI.registerHook('onCoreClick', (e) => { // クリックパワーの10%をタイムシャードに変換して加算する const clickPower = window.ModAPI.getCalculatedClickPower(); const bonus = D(clickPower).mul(0.1); window.ModAPI.addTimeShards(bonus.toNumber()); CustomModState.totalBonusEarned += bonus.toNumber(); }); console.log("[ProMod] Advanced hooks and state trackers initialized successfully.");
